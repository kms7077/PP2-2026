# [HW01] BMI 계산 및 Turtle GUI 출력 프로그램

## 1. 팀 소개 및 역할 분담
* **팀명**: Team8
* **팀원 및 역할**:
  * **김민석 (팀장)**: 프론트엔드 (Turtle 표 틀 그리기 `draw_table`) 및 최종 제출
  * **김윤성**: 백엔드 (파일 읽기 및 BMI 연산 `file_read`, `cal_bmi`, `data_store`)
  * **유강훈**: 프론트엔드 (표 내부 데이터 텍스트 출력 `draw_text`)
  * **이원준**: 보고서 (`README.md`) 작성

---

## 2. 과제 개요
* `health.txt` 파일의 개인 신체 데이터(전화번호, 이름, 키, 몸무게)를 파싱함.
* BMI 공식을 적용해 수치를 산출하고 비만도(저체중/표준/과체중/비만)를 판정함.
* Python의 `turtle` 그래픽 모듈을 활용하여 데이터 개수에 맞춰 가변적인 표 형태(GUI)로 결과를 출력함.

---

## 3. 프로그램 설계 및 구현
1. **백엔드 (`김윤성`)**
   * **데이터 파일 입력 로직**: `file_read()` 함수를 통해 메모장에 있는 데이터를 읽어와 분리함.
   * **BMI 계산 로직**: `cal_bmi()` 함수로 $\text{BMI} = \frac{\text{몸무게(kg)}}{(\text{키(m)})^2}$ 공식을 계산하고 소견을 판정함.
   * **데이터 정제**: 계산된 결과를 `clean_data` 리스트로 구조화하여 저장함.
   * **모듈화 및 테스트**: 각 기능을 단위 모듈로 분리하여 동작을 테스트함.
2. **프론트엔드 (`김민석`, `유강훈`)**
   * **표 테두리 생성**: `draw_table()` 함수로 데이터 개수에 맞춰 가변적인 표 레이아웃을 그림 (`김민석`).
   * **데이터 렌더링**: `draw_text()` 함수로 백엔드의 `clean_data`를 전달받아 지정된 셀 위치에 헤더 및 텍스트를 정렬 출력함 (`유강훈`).

## 5. 팀 프로젝트 소감
* **김민석**: 이번 팀플로 처음으로 사람들과 같이 코딩을 해봤고, 역할 분할이 편한 이유를 알 수 있게 됨.
* **김윤성**: 처음에는 절대경로를 써야 하는 줄 알고 접근했다가 타 컴퓨터 실행 문제를 파악한 후 상대경로로 수정함. OS를 직접 다루는 프로그래밍에서는 경로 처리가 중요함을 느꼈으며, 협업적인 관점에서 코드 구조를 고민하는 계기가 됨.
* **유강훈**: 2차원 데이터 배열과 터틀 그래픽 좌표계를 연동하는 로직을 구현하며 반복문 활용 및 좌표 계산 역량을 키움. 초기 소통 부족으로 인한 아쉬움을 바탕으로, 협업 시 명확한 역할 공유와 지속적인 소통의 필요성을 깨닫는 계기가 됨.
* **이원준**: 팀원들과 구현 내용을 나누어 종합하고 보고서를 작성하면서 소통과 팀합의 중요성을 크게 깨달음.
